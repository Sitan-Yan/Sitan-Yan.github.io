## 公开内容取舍

方法 PDF 用于理解研究背景和系统用途。网页只介绍设备组成、观测困难、总体目标和个人工作，不公开以下内容：

- 核心公式、算法推导、详细流程图和具体策略切换条件；
- 控制器目标函数、模型矩阵、求解器流程、权重及阈值；
- 校准细节、约束的具体构造、代码及实现参数。

按作者后续要求，已加入两张仅展示运动与几何关系的方法图，配合文字说明；核心推导、求解步骤和参数仍不公开。

PDF 的实验部分是验证方案，未给出完整实验结果。因此已从第二个项目首页摘要中移除原有成功率、频率、精度和具体搜索方法等描述；新页面不把演示视频作为定量实验或完整新方法验证。论文列表中的题目及投稿计划保持原样。

视频源文件早于本项目主页所列时间，适合作为平台操作演示，不能直接证明当前论文版本中每一项方法均在这些视频中执行。页面据此使用 System Demonstrations、qualitative demonstrations 等表述。

本说明为维护资料，没有加入网页导航；不应将未公开公式、参数或完整论文追加到 HTML 注释或网站资产目录。
